# Inventory Management v0.1.4

- Fixes a sync problem where one computer's TE Test Equipment changes could stop reaching everyone else without any warning. Computers now merge the team snapshot record by record (newest change wins) instead of skipping it, so nobody's work gets stranded.
- A computer that holds changes no longer on the team share now republishes them automatically.
- A computer can no longer publish an out-of-date snapshot over newer team data.
- If the team share was last updated by a newer version, the app asks you to click Update and stops publishing snapshots until you do. Your edits still sync.
- TE Storage is now called **EVCS Storage**. Your data, columns, and shared folder are unchanged.

Existing databases, shared folders, and updater signing identity are preserved. Everyone should update to 0.1.4 using the in-app Update button.
