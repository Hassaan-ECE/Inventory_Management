# Inventory Management v0.1.3

- Adds TE Storage with separate local saving and automatic team sync, including offline edits.
- Supports adding, editing, deleting, searching, and sorting storage items.
- Columns: PN #, PR #, PO #, Manufacturer, Model, Description, Qty, Location, and Notes. PR # and Description start hidden.
- Right-click any table header to choose columns; Shift+F10 also opens the picker. Column choices persist on each computer.
- Renames the inventory display from TE Storage Room to TE Storage and removes its manual sync button. Automatic sync and sync status remain available.

Existing inventory databases, storage locations, shared folders, and updater signing identity are preserved. Storage data is synchronized from the team share, not embedded in the installer. ME Storage remains a placeholder.

Install from the team product share or use the in-app Update button on an existing installation.
